# Monetiza3D organization defaults

This repository contains public GitHub community health files and the source of reusable engineering standards for the Monetiza3D organization.

GitHub can use these files as defaults for eligible repositories. Defaults do not synchronize into existing repositories and do not replace repository-local workflows, Dependabot configuration, access controls, or required checks. New product repositories must be bootstrapped from the templates under `templates/` and checked against `docs/repository-onboarding.md`.
